lxml-6.1.0

Introduction to lxml Module

lxml provides Python bindings for libxslt-1.1.45 and libxml2-2.15.3.

Package Information

  • Download (HTTP): https://files.pythonhosted.org/packages/source/l/lxml/lxml-6.1.0.tar.gz

  • Download SHA256 Sum: bfd57d8008c4965709a919c3e9a98f76c2c7cb319086b3d26858250620023b13

  • Download size: 4,099 KB

  • Estimated disk space required: 102.4M

  • Estimated build time: less than 1.0 SBU

lxml Dependencies

Required

libxslt-1.1.45

Installation of lxml

To build the Python 3 module, run: 

pip3 wheel -w dist --no-build-isolation --no-deps --no-cache-dir $PWD

To install the module, issue the following command as the root user: 

pip3 install --no-index --find-links dist --no-user lxml

Contents

Installed Libraries: None
Installed Directories: /usr/lib/python3.14/site-packages/lxml and /usr/lib/python3.14/site-packages/lxml-6.1.0.dist-info
