Pathspec-1.0.4

Introduction to Pathspec Module

Pathspec is a utility library for pattern matching of file paths.

Package Information

  • Download (HTTP): https://files.pythonhosted.org/packages/source/p/pathspec/pathspec-1.0.4.tar.gz

  • Download SHA256 Sum: 0210e2ae8a21a9137c0d470578cb0e595af87edaa6ebf12ff176f14a02e0e645

  • Download size: 128 KB

  • Estimated disk space required: 880.3 KB

  • Estimated build time: less than 0.1 SBU

Installation of Pathspec

Build the module: 

pip3 wheel -w dist --no-build-isolation --no-deps --no-cache-dir $PWD

Now Install, as the root user: 

pip3 install --no-index --find-links dist --no-user pathspec

To test the installation, issue pytest.
