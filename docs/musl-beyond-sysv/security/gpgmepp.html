gpgmepp-2.0.0

Introduction to gpgmepp

The gpgmepp package provides a C++ wrapper to gpgme-2.0.1.

Package Information

  • Download (HTTP): https://www.gnupg.org/ftp/gcrypt/gpgmepp/gpgmepp-2.0.0.tar.xz

  • Download SHA256 Sum: d4796049c06708a26f3096f748ef095347e1a3c1e570561701fe952c3f565382

  • Download size: 116 KB

  • Estimated disk space required: 6.9 MM

  • Estimated build time: less than 0.5 SBU

gpgmepp Dependencies

Required

gpgme-2.0.1

Installation of gpgmepp

Prepare gpgmepp by running: 

cmake -B build -D CMAKE_INSTALL_PREFIX=/usr

Build gpgmepp by running: 

cmake --build build

This package does not come with a test suite.

Now Install, as the root user: 

cmake --install build

Command Explanations

-B build: This option tells cmake to place the build files in the build directory.

--build: This option invokes the build process in the specified build directory.

--install: This option installs the built files from the specified build directory into the system.

Contents

Installed Program: None
Installed Libraries: libgpgmepp.so
Installed Directory: /usr/lib/cmake/Gpgmepp and /usr/include/gpgme++

Short Descriptions

libgpgmepp.so

contains the C++ gpgme API functions
