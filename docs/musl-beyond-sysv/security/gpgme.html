gpgme-2.0.1

Introduction to gpgme

The gpgme package is a C library that allows cryptography support to be added to a program. It is designed to make access to public key crypto engines like GnuPG or GpgSM easier for applications. gpgme provides a high-level crypto API for encryption, decryption, signing, signature verification and key management.

Installation of gpgme

Prepare gpgme by running:

First, fix a missing definition of ino_t and off_t: 

patch -Np1 -i ../gpgme-lfs64.patch
mkdir build
cd build

../configure --prefix=/usr       \
             --disable-static

Build gpgme by running: 

make

To test the results, you should have GnuPG-2.5.20 installed. If so, run: 

make -k check

Now Install, as the root user: 

make install

Command Explanations

--disable-static: This switch prevents installation of static versions of the libraries.

--disable-gpg-test: Use this switch if GnuPG-2.5.20 is not installed.

Contents

Installed Program: gnupg-key-manage, gpgme-json, and gpgme-tool
Installed Libraries: libgpgme.so
Installed Directory: /usr/share/common-lisp/source/gpgme

Short Descriptions

gnupg-key-manage

performs a variety of operations on GPG keys, including identifying keys and deleting them

gpgme-json

outputs gpgme commands in JSON format

gpgme-tool

is an assuan server exposing gpgme operations, such as printing fingerprints and keyids with keyservers

libgpgme.so

contains the gpgme API functions
