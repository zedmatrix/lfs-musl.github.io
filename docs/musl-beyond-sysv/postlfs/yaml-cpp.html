Yaml-cpp-0.9.0

Introduction to yaml-cpp

The yaml-cpp package provides a compiler for writing C extensions for the Python language.

Package Information

  • Download (HTTP): https://github.com/jbeder/yaml-cpp/archive/refs/tags/yaml-cpp-0.9.0.tar.gz

  • Download SHA256 Sum: 25cb043240f828a8c51beb830569634bc7ac603978e0f69d6b63558dadefd49a

  • Download size: 1,031 KB

  • Estimated disk space required: 10.8 MB

  • Estimated build time: less than 0.5 SBU

Installation of Yaml-cpp

Prepare yaml-cpp by running: 

cmake -B build \
          -G Ninja \
          -D CMAKE_INSTALL_PREFIX=/usr \
          -D CMAKE_BUILD_TYPE=Release  \
          -D YAML_BUILD_SHARED_LIBS=ON

Build yaml-cpp by running: 

ninja -C build

This package does not have a testsuite.

Now Install, as the root user: 

ninja -C build install

Note

To Build a static library, issue: 

cmake -B build-static \
      -G Ninja \
      -D CMAKE_INSTALL_PREFIX=/usr \
      -D CMAKE_BUILD_TYPE=Release  \
      -D YAML_BUILD_SHARED_LIBS=OFF

ninja -C build-static

cp -v build-static/libyaml-cpp.a /usr/lib
