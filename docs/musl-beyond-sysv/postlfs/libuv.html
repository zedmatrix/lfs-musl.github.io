libuv-1.52.1

Introduction to libuv

The libuv package is a multi-platform support library with a focus on asynchronous I/O.

Package Information

  • Download (HTTP): https://dist.libuv.org/dist/v1.52.1/libuv-v1.52.1.tar.gz

  • Download SHA256 sum: 66d511b9e6e334c0e62279eb234fbfb2b3110b1479c09b95b44c7afca8cff9e7

  • Download size: 1,323 KB

  • Estimated disk space required: 14.4 MB

  • Estimated build time: less than 0.5 SBU

Installation of libuv

Prepare libuv by running: 

sh autogen.sh
./configure --prefix=/usr --disable-static

Build libuv by running: 

make

If you want to run the tests, as a non-root user: 

make check

Now, as the root user: 

make install

Contents

Installed Programs: None
Installed Library: libuv.so
Installed Directory: /usr/include/uv

Short Descriptions

libuv.so

contains API functions for asynchronous I/O operations
