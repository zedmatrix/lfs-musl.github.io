duktape-2.7.0

Introduction to duktape

duktape is an embeddable Javascript engine, with a focus on portability and compact footprint.

Package Information

  • Download (HTTP): https://duktape.org/duktape-2.7.0.tar.xz

  • Download SHA256 Sum: 90f8d2fa8b5567c6899830ddef2c03f3c27960b11aca222fa17aa7ac613c2890

  • Download size: 1,002 KB

  • Estimated disk space required: 20.5M

  • Estimated build time: less than 0.5 SBU

Installation of duktape

Build duktape by running the following commands: 

sed -i 's/-Os/-O2/' Makefile.sharedlibrary

make -f Makefile.sharedlibrary INSTALL_PREFIX=/usr

Now Install, as the root user: 

make -f Makefile.sharedlibrary INSTALL_PREFIX=/usr install

Contents

Installed Directories: None
