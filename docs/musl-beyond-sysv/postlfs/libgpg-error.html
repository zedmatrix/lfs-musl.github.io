libgpg-error-1.61

Introduction to libgpg-error

The libgpg-error package contains a library that defines common error values for all GnuPG components.

Package Information

  • Download (HTTP): https://www.gnupg.org/ftp/gcrypt/libgpg-error/libgpg-error-1.61.tar.bz2

  • Download SHA256 sum: 7a85413f2bc354f4f8aa832b718af122e48965e9e0eb9012ee659c13c6385c93

  • Download size: 1,098 KB

  • Estimated disk space required: 10.4M

  • Estimated build time: less than 0.5 SBU

Installation of libgpg-error

Prepare libgpg-error by running: 

./configure --prefix=/usr --sysconfdir=/etc
make

To test the results, issue: 

make check

Now Install, as the root user: 

make install

install -v -m644 -D README /usr/share/doc/libgpg-error-1.61/README

Contents

Installed Programs: gpg-error, gpgrt-config, and yat2m
Installed Library: libgpg-error.so
Installed Directories: /usr/share/common-lisp/source/gpg-error, /usr/share/libgpg-error, and /usr/share/doc/libgpg-error-1.61

Short Descriptions

gpg-error

is used to determine libgpg-error error codes

gpgrt-config

is a pkg-config style tool for querying the information about installed version of libgpg-error

yat2m

extracts man pages from a Texinfo source

libgpg-error.so

contains the libgpg-error API functions
