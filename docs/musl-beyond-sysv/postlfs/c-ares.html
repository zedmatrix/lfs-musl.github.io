c-ares-1.34.6

Introduction to c-ares

c-ares is a C library for asynchronous DNS requests.

Package Information

  • Download (HTTP): https://github.com/c-ares/c-ares/releases/download/v1.34.6/c-ares-1.34.6.tar.gz

  • Download SHA256 Sum: 912dd7cc3b3e8a79c52fd7fb9c0f4ecf0aaa73e45efda880266a2d6e26b84ef5

  • Download size: 994 KB

  • Estimated disk space required: 7.3M

  • Estimated build time: less than 0.5 SBU

c-ares Dependencies

Required

CMake-4.3.2

Installation of c-ares

Prepare c-ares by running: 

cmake -B build -D CMAKE_INSTALL_PREFIX=/usr
cmake --build build

This package does not include a test suite.

Now Install, as the root user: 

cmake --install build

Contents

Installed Programs: adig and ahost
Installed Libraries: libcares.so
Installed Directories: None

Short Descriptions

adig

queries information from DNS servers

ahost

prints the A or AAAA record associated with a hostname or IP address

libcares.so

is a C library for asynchronous DNS requests
