5.19. Gmp-6.3.0

The GMP package contains math libraries. These have useful functions for arbitrary precision arithmetic.

Package Information

  • Download HTTP: https://mirror.csclub.uwaterloo.ca/gnu/gmp/gmp-6.3.0.tar.xz

  • Download SHA256 Sum: a3c2b80201b89e68616f4ad30bc66aee4927c3ce50e33929ca819d5c43538898

  • Download Size: 2,045 KB

  • Estimated Disk Space: 39.3M

  • Estimated Build Time: less than 0.5 SBU

5.19.1. Installation of Gmp

Prepare Gmp for compilation: 

sed -i '/long long t1;/,+1s/()/(...)/' configure
./configure --prefix=/usr \
            --enable-cxx  \
            --disable-static \
            --docdir=/usr/share/doc/gmp-6.3.0

To Compile the Package, issue: 

make
make html

To Test the Package, issue: 

make check 2>&1 | tee gmp-check-log

Now Install the Package, as the root user: 

make install
make install-html
awk '/# PASS:/{total+=$3} ; END{print total}' gmp-check-log

Note

Ensure that at least 199 tests in the test suite have passed.
