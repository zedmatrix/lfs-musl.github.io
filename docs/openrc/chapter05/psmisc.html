5.30. Psmisc-23.7

The Psmisc package contains programs for displaying information about running processes.

Package Information

  • Download HTTP: https://sourceforge.net/projects/psmisc/files/psmisc/psmisc-23.7.tar.xz

  • Download SHA256 Sum: 58c55d9c1402474065adae669511c191de374b0871eec781239ab400b907c327

  • Download Size: 422 KB

  • Estimated Disk Space: 4.4M

  • Estimated Build Time: less than 0.5 SBU

5.30.1. Installation of Psmisc

Prepare Psmisc for compilation: 

./configure --prefix=/usr

To Compile the Package, issue: 

make

Now Install the Package, as the root user: 

make install

5.30.2. Contents of Psmisc

Installed programs: killall, pslog, prtstat, pstree, and fuser
Not Installed : peekfd (not built on musl)

Short Descriptions

fuser

Reports the Process IDs (PIDs) of processes that use the given files or file systems

pstree

Displays running processes as a tree (creates a symlink pstree.x11)

prtstat

Prints information about a process

pslog

Reports current logs path of a process

killall

Kills processes by name; it sends a signal to all processes running any of the given commands
