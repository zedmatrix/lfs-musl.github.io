5.17. Pkgconf-2.5.1

The pkgconf package is a successor to pkg-config and contains a tool for passing the include path and/or library paths to build tools.

Package Information

  • Download HTTP: https://distfiles.ariadne.space/pkgconf/pkgconf-2.5.1.tar.xz

  • Download SHA256 Sum: cd05c9589b9f86ecf044c10a2269822bc9eb001eced2582cfffd658b0a50c243

  • Download Size: 320 KB

  • Estimated Disk Space: 3.5M

  • Estimated Build Time: less than 0.5 SBU

5.17.1. Installation of Pkgconf

Prepare Pkgconf for compilation: 

./configure --prefix=/usr \
            --disable-static \
            --docdir=/usr/share/doc/pkgconf-2.5.1

To Compile the Package, issue: 

make

Now Install the Package, as the root user: 

make install

ln -sv pkgconf /usr/bin/pkg-config
ln -sv pkgconf.1 /usr/share/man/man1/pkg-config.1

5.17.2. Contents of

Installed programs: pkgconf, pkg-config (symlink to pkgconf), and bomtool
Installed libraries: libpkgconf.so.7.0.0
Installed directories: usr/share/doc/pkgconf-2.5.1

Short Descriptions

pkgconf

Returns meta information for the specified library or package

bomtool

Generates a Software Bill Of Materials from pkg-config .pc files

libpkgconf

Contains most of pkgconf's functionality, while allowing other tools like IDEs and compilers to use its frameworks
