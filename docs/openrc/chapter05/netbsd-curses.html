5.28. Netbsd-curses-0.3.2

This is a port of netbsd's curses library for usage on Linux systems (tested and developed on sabotage linux, based on musl libc).

Package Information

  • Download HTTP: http://ftp.barfooze.de/pub/sabotage/tarballs/netbsd-curses-0.3.2.tar.xz

  • Download SHA256 Sum: d28358b833e6cabcf229fecef98c649e2e90c29858aa34220476faf0e5ce10a1

  • Download Size: 522 KB

  • Estimated Disk Space: 4.5M

  • Estimated Build Time: less than 0.5 SBU

5.28.1. Installation of Netbsd-curses

Prepare Netbsd-curses for compilation:

To Compile the Package, issue: 

make -E "CPPFLAGS=-DTERMINFO_COMPAT" PREFIX="/usr" all-dynamic

Now Install the Package, as the root user: 

make -E "CPPFLAGS=-DTERMINFO_COMPAT" PREFIX="/usr" install-dynamic

5.28.2. Contents of Netbsd-curses

Installed programs: tic, tset, tput, infocmp, tabs, and clear (shell script)
Installed libraries: libterminfo.so, libcurses.so, libpanel.so, libmenu.so, and libform.so
Installed directories: /usr/include/

Short Descriptions

tic

The terminfo entry-description compiler that translates a terminfo file from source format into the binary format needed for the ncurses library routines

tset

Can be used to initialize terminals

tput

Makes the values of terminal-dependent capabilities available to the shell; it can also be used to reset or initialize a terminal or report its long name

infocmp

Compares or prints out terminfo descriptions

tabs

Clears and sets tab stops on a terminal

tic

A POSIX shell script, Clears the screen, if possible

libterminfo

has a built-in termcap database with entries for ansi, dumb, rxvt-unicode-256color, screen, screen-256color, st, tmux, tmux-256color, vt100, vt220, wsvt25, xterm, and xterm-256color terminals, which should handle the vast majority of cases.

libcurses

Contains functions to display text in many complex ways on a terminal screen

libpanel

Contains functions to implement panels

libmenu

Contains functions to implement menus

libform

Contains functions to implement forms
