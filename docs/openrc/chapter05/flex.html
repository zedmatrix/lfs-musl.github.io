5.16. Flex-2.6.4

The Flex package contains a utility for generating programs that recognize patterns in text.

Package Information

  • Download HTTP: https://github.com/westes/flex/releases/download/v2.6.4/flex-2.6.4.tar.gz

  • Download SHA256 Sum: e87aae032bf07c26f85ac0ed3250998c37621d95f8bd748b31f15b33c45ee995

  • Download Size: 1,386 KB

  • Estimated Disk Space: 10.9M

  • Estimated Build Time: less than 0.5 SBU

5.16.1. Installation of Flex

Prepare Flex for compilation: 

./configure --prefix=/usr \
            --disable-static \
            --docdir=/usr/share/doc/flex-2.6.4

To Compile the Package, issue: 

make

Now Install the Package, as the root user: 

make install
ln -sv flex /usr/bin/lex
ln -sv flex.1 /usr/share/man/man1/lex.1

5.16.2. Contents of

Installed programs: flex, (symlinks to flex) flex++, lex
Installed libraries: libfl.so.2.0.0
Installed directories: /usr/share/doc/flex-2.6.4, /usr/share/man/man1

Short Descriptions

flex

A tool for generating programs that recognize patterns in text

flex++

A symbolic link to flex, An extension that is used for generating C++ code and classes.

libfl

The flex library
