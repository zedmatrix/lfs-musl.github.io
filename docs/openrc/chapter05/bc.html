5.15. Bc-7.0.3

The Bc package contains an arbitrary precision numeric processing language.

Package Information

  • Download HTTP: https://github.com/gavinhoward/bc/releases/download/7.0.3/bc-7.0.3.tar.xz

  • Download SHA256 Sum: 91eb74caed0ee6655b669711a4f350c25579778694df248e28363318e03c7fc4

  • Download Size: 464 KB

  • Estimated Disk Space: 5.6M

  • Estimated Build Time: less than 0.5 SBU

5.15.1. Installation of Bc

Prepare Bc for compilation: 

CC='gcc -std=c99' ./configure --prefix=/usr -G -O3 -e

To Compile the Package, issue: 

make

To Test the Package, issue: 

make test

Now Install the Package, as the root user: 

make install

5.15.2. Contents of

Installed programs: bc, dc
Installed libraries: None
Installed directories: /usr/share/man/man1

A command line calculator

dc
