5.22. Attr-2.5.2

The Attr package contains utilities to administer the extended attributes of filesystem objects.

Package Information

  • Download HTTP: https://download.savannah.gnu.org/releases/attr/attr-2.5.2.tar.gz

  • Download SHA256 Sum: 39bf67452fa41d0948c2197601053f48b3d78a029389734332a6309a680c6c87

  • Download Size: 481 KB

  • Estimated Disk Space: 3.1M

  • Estimated Build Time: less than 0.5 SBU

5.22.1. Installation of Attr

Prepare Attr for compilation, by adding a missing include: 

sed -Ee "1s|(.*)|#include <libgen.h>\n\1|;" -i tools/attr.c

./configure --prefix=/usr \
            --disable-static \
            --sysconfdir=/etc \
            --docdir=/usr/share/doc/attr-2.5.2

To Compile the Package, issue: 

make

Now Install the Package, as the root user: 

make install

5.22.2. Contents of

Installed programs: getfattr, and setfattr
Installed libraries: libattr.so.1.1.2502
Installed directories: /usr/share/doc/attr-2.5.2, /usr/include/attr, and /etc/xattr.conf

Short Descriptions

attr

Extends attributes on filesystem objects

getfattr

Gets the extended attributes of filesystem objects

setfattr

Sets the extended attributes of filesystem objects

libattr

Contains the library functions for manipulating extended attributes
