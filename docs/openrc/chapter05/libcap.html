5.24. Libcap-2.77

The Libcap package implements the userspace interface to the POSIX 1003.1e capabilities available in Linux kernels.

Package Information

  • Download HTTP: https://www.kernel.org/pub/linux/libs/security/linux-privs/libcap2/libcap-2.77.tar.xz

  • Download SHA256 Sum: 897bc18b44afc26c70e78cead3dbb31e154acc24bee085a5a09079a88dbf6f52

  • Download Size: 195 KB

  • Estimated Disk Space: 1.2M

  • Estimated Build Time: less than 0.5 SBU

5.24.1. Installation of Libcap

Prepare Libcap for compilation:

To Compile the Package, and remove the static library issue: 

sed -i '/install -m.*STA/d' libcap/Makefile

make prefix=/usr lib=lib

Now Install the Package, as the root user: 

make prefix=/usr lib=lib install

5.24.2. Contents of

Installed programs: getpcaps, getcap, setcap, and capsh
Installed libraries: libcap.so.2.77 and libpsx.so.2.77
Installed directories: /usr/include/sys,

Short Descriptions

capsh

A shell wrapper to explore and constrain capability support

getpcaps

Displays the capabilities of the queried process(es)

getcap

Examines file capabilities

setcap

Sets file capabilities

libcap

Contains the library functions for manipulating POSIX 1003.1e capabilities

libpsx

Contains functions to support POSIX semantics for syscalls associated with the pthread library
