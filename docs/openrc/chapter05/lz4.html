5.9. Lz4-1.10.0

Lz4 is a lossless compression algorithm, providing compression speed greater than 500 MB/s per core.

Package Information

  • Download HTTP: https://github.com/lz4/lz4/releases/download/v1.10.0/lz4-1.10.0.tar.gz

  • Download SHA256 Sum: 537512904744b35e232912055ccf8ec66d768639ff3abe5788d90d792ec5f48b

  • Download Size: 378 KB

  • Estimated Disk Space: 3M

  • Estimated Build Time: less than 0.5 SBU

5.9.1. Installation of Lz4

Prepare Lz4 for compilation:

To Compile the Package, issue: 

make PREFIX=/usr

Now Install the Package, as the root user: 

make PREFIX=/usr install

5.9.2. Contents of Lz4

Installed programs: lz4, lz4c, lz4cat, unlz4
Installed libraries: liblz4.a, liblz4.so.1.10.0
Installed directories: None
