5.5. Timezone-musl-2026a

The Time Zone Database (often called tz or zoneinfo) contains code and data that represent the history of local time

Package Information

  • Download HTTP: https://gitlab.com/zed-linuxfromscratch/timezone-musl/-/archive/2026a/timezone-musl-2026a.tar.gz

  • Download SHA256 Sum: cdd676425447eec1ecab7d94edb59933e0261bb1cb11ae28f8a85dc9bd1b3ad3

5.5.1. Installation of Timezone-musl

Prepare Timezone-musl for compilation:

To Compile the Package, issue: 

make CC=gcc zic zdump tzselect

Now Install the Package, as the root user: 

install -m755 zic /usr/bin
install -m755 zdump /usr/bin
install -m755 tzselect /usr/bin

Install and set up the time zone data with the following: 

ZONEINFO=/usr/share/zoneinfo
mkdir -pv $ZONEINFO/{posix,right}

for tz in etcetera southamerica northamerica europe africa antarctica  \
  asia australasia backward; do
  zic -L /dev/null   -d $ZONEINFO       ${tz}
  zic -L /dev/null   -d $ZONEINFO/posix ${tz}
  zic -L leapseconds -d $ZONEINFO/right ${tz}
done

cp -v zone.tab zone1970.tab iso3166.tab $ZONEINFO
zic -d $ZONEINFO -p America/New_York
unset ZONEINFO tz

Then create the /etc/localtime file by running: 

ln -sfv /usr/share/zoneinfo/<xxx> /etc/localtime

Replace <xxx> with the name of the time zone selected (e.g., Canada/Eastern).

5.5.2. Contents of Timezone-Musl

Installed programs: zic, zdump, tzselect
Installed libraries: None
Installed directories: /usr/share/zoneinfo{posix,right}

Short Descriptions

zic

The time zone compiler

zdump

The time zone dumper

tzselect

Asks the user about the location of the system and reports the corresponding time zone description
