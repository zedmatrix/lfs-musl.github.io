5.25. Libxcrypt-4.5.2

The Libxcrypt package contains a modern library for one-way hashing of passwords.

Package Information

  • Download HTTP: https://github.com/besser82/libxcrypt/releases/download/v4.5.2/libxcrypt-4.5.2.tar.xz

  • Download SHA256 Sum: 71513a31c01a428bccd5367a32fd95f115d6dac50fb5b60c779d5c7942aec071

  • Download Size: 654 KB

  • Estimated Disk Space: 5.4M

  • Estimated Build Time: less than 0.5 SBU

5.25.1. Installation of Libxcrypt

Prepare Libxcrypt for compilation: 

./configure --prefix=/usr \
            --enable-hashes=all      \
            --enable-obsolete-api=no \
            --disable-static         \
            --disable-failure-tokens

To Compile the Package, issue: 

make CFLAGS="-Wno-error=cpp"

To Test the Package, issue: 

make check

Now Install the Package, as the root user: 

make install
