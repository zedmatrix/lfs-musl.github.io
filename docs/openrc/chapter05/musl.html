5.3. Musl-1.2.6

The Musl Package contains an alternative main C library.

Package Information

  • Download HTTP: https://musl.libc.org/releases/musl-1.2.6.tar.gz

  • Download SHA256 Sum: d585fd3b613c66151fc3249e8ed44f77020cb5e6c1e635a616d3f9f82460512a

  • Download Size: 1,057 KB

  • Estimated Disk Space: 25.1M

  • Estimated Build Time: less than 0.5 SBU

5.3.1. Installation of Musl

Prepare Musl for compilation: 

./configure --prefix=/usr \
            --with-malloc=rpmalloc

To Compile the Package, issue: 

make

Now Install the Package, as the root user: 

make install

The /etc/nsswitch.conf file needs to be created because the Glibc defaults do not work well in a networked environment.

Create a new file /etc/nsswitch.conf by running the following: 

cat > /etc/nsswitch.conf << "EOF"
# Begin /etc/nsswitch.conf

passwd: files
group: files
shadow: files

hosts: files dns
networks: files

protocols: files
services: files
ethers: files
rpc: files

# End /etc/nsswitch.conf
EOF

By default, the dynamic loader (/lib/ld-musl-x86_64.so.1) searches through /usr/lib for dynamic libraries that are needed by programs as they are run. However, if there are libraries in directories other than /usr/lib, these need to be added to the /etc/ld-musl-x86_64.path file in order for the dynamic loader to find them. Two directories that are commonly known to contain additional libraries are /usr/local/lib and /opt/lib, so add those directories to the dynamic loader's search path.

Create a new file /etc/ld-musl-x86_64.path by running the following: 

cat > /etc/ld-musl-x86_64.path << "EOF"
# Begin /etc/ld.so.conf

/usr/lib

/usr/local/lib

/opt/lib

# End /etc/ld-musl-x86_64.path
EOF

Add the ldd program as a symlink to libc: 

case $(uname -m) in
  i?86) ln -sfv ../lib/ld-musl.so.1 /usr/bin/ldd
  ;;
  x86_64) ln -sfv ../lib/ld-musl-x86_64.so.1 /usr/bin/ldd
  ;;
esac

Add the ldconfig program as a stub for compatibility: 

cat > /sbin/ldconfig << "EOF"
#!/bin/sh
# musl does not use ldconfig - stub for compatibility
exit 0
EOF
chmod -v +x /usr/sbin/ldconfig

5.3.2. Contents of

Installed programs: ldd (symlink to ld-musl-x86_64.so.1), ld-x86_64-musl.so.1 (symlink to libc.so) ldconfig (stub for compact)
Installed libraries: libc.{a,so}, stub archive (libm.a, librt.a, libpthread.a, libcrypt.a, libutil.a, libxnet.a, libresolv.a, libdl.a)
Installed objects: Scrt1.o ,crt1.o ,rcrt1.o ,crti.o ,and crtn.o
