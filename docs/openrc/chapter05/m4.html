5.14. M4-1.4.21

The M4 package contains a macro processor.

Package Information

  • Download HTTP: https://mirror.csclub.uwaterloo.ca/gnu/m4/m4-1.4.21.tar.xz

  • Download SHA256 Sum: f25c6ab51548a73a75558742fb031e0625d6485fe5f9155949d6486a2408ab66

  • Download Size: 2,031 KB

  • Estimated Disk Space: 28.9M

  • Estimated Build Time: less than 0.5 SBU

5.14.1. Installation of M4

Prepare M4 for compilation: 

./configure --prefix=/usr

To Compile the Package, issue: 

make

Now Install the Package, as the root user: 

make install

5.14.2. Contents of

Installed programs: m4
Installed libraries: None
Installed directories: /usr/share/man/man1, /usr/share/info

Short Descriptions

m4

Copies the given files while expanding the macros that they contain.
