5.13. Pcre2-10.47

The pcre2 package contains a new generation of the Perl Compatible Regular Expression libraries.

Package Information

  • Download HTTP: https://github.com/PCRE2Project/pcre2/releases/download/pcre2-10.47/pcre2-10.47.tar.bz2

  • Download SHA256 Sum: 47fe8c99461250d42f89e6e8fdaeba9da057855d06eb7fc08d9ca03fd08d7bc7

  • Download Size: 2,095 KB

  • Estimated Disk Space: 19.3M

  • Estimated Build Time: less than 0.5 SBU

5.13.1. Installation of Pcre2

Prepare Pcre2 for compilation: 

./configure --prefix=/usr \
            --disable-static  \
            --enable-unicode  \
            --enable-jit      \
            --enable-pcre2-16 \
            --enable-pcre2-32 \
            --enable-pcre2grep-libz   \
            --enable-pcre2grep-libbz2 \
            --enable-pcre2test-libreadline \
            --docdir=/usr/share/doc/pcre2-10.47

To Compile the Package, issue: 

make

To Test the Package, issue: 

make check

Now Install the Package, as the root user: 

make install

5.13.2. Contents of Pcre2

Installed programs: pcre2grep, pcre2test, pcre2-config
Installed libraries: libpcre2-8.so.0.15.0, libpcre2-16.so.0.15.0, libpcre2-32.so.0.15.0, libpcre2-posix.so.3.0.7,
Installed directories: /usr/share/doc/pcre2-10.47

Short Descriptions

pcre2grep

is a version of grep that understands Perl compatible regular expressions

pcre2test

can test a Perl compatible regular expression

libpcre2-8

The 32 Character Library.
