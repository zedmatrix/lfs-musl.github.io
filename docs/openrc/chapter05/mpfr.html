5.20. Mpfr-4.2.2

The MPFR package contains functions for multiple precision math.

Package Information

  • Download HTTP: https://mirror.csclub.uwaterloo.ca/gnu/mpfr/mpfr-4.2.2.tar.xz

  • Download SHA256 Sum: b67ba0383ef7e8a8563734e2e889ef5ec3c3b898a01d00fa0a6869ad81c6ce01

  • Download Size: 1,470 KB

  • Estimated Disk Space: 32.4M

  • Estimated Build Time: less than 0.5 SBU

5.20.1. Installation of Mpfr

Prepare Mpfr for compilation: 

./configure --prefix=/usr \
            --disable-static \
            --enable-thread-safe \
            --docdir=/usr/share/doc/mpfr-4.2.2

To Compile the Package, issue: 

make
make html

To Test the Package, issue: 

make check 2>&1 | tee mpfr-check-log

Now Install the Package, as the root user: 

make install
make install-html

awk '/# PASS:/{total+=$3} ; END{print total}' mpfr-check-log

Note

Ensure that at least 198 tests in the test suite have passed.
