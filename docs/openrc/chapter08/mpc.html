5.21. Mpc-1.4.0

The MPC package contains a library for the arithmetic of complex numbers with arbitrarily high precision and correct rounding of the result.

Package Information

  • Download HTTP: https://mirror.csclub.uwaterloo.ca/gnu/mpc/mpc-1.4.0.tar.xz

  • Download SHA256 Sum: 3210b3a546b1cb00c296ca360891d7740ee6ff06deb02a27a35b20cd3c0bb1a5

  • Download Size: 520 KB

  • Estimated Disk Space: 17.6M

  • Estimated Build Time: less than 0.5 SBU

5.21.1. Installation of Mpc

Prepare Mpc for compilation: 

./configure --prefix=/usr \
            --disable-static \
            --docdir=/usr/share/doc/mpc-1.4.0

To Compile the Package, issue: 

make
make html

To Test the Package, issue: 

make check 2>&1 | tee mpc-check-log

Now Install the Package, as the root user: 

make install
make install-html

awk '/# PASS:/{total+=$3} ; END{print total}' mpc-check-log

Note

Ensure that at least 75 tests in the test suite have passed.
