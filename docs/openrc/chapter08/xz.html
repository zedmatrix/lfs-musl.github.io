5.8. Xz-5.8.3

The Xz package contains programs for compressing and decompressing files.

Package Information

  • Download HTTP: https://github.com//tukaani-project/xz/releases/download/v5.8.3/xz-5.8.3.tar.xz

  • Download SHA256 Sum: fff1ffcf2b0da84d308a14de513a1aa23d4e9aa3464d17e64b9714bfdd0bbfb6

  • Download Size: 1,512 KB

  • Estimated Disk Space: 19.3M

  • Estimated Build Time: less than 0.5 SBU

5.8.1. Installation of Xz

Prepare Xz for compilation: 

./configure --prefix=/usr   \
            --enable-shared \
            --enable-static \
            --docdir=/usr/share/doc/xz-5.8.3

To Compile the Package, issue: 

make

To Test the Package, issue: 

make check

Now Install the Package, as the root user: 

make install

5.8.2. Contents of Xz

Installed programs: xz, xzdec, and lzmadec, lzmainfo, xzdiff, xzgrep, xzless, xzmore
Installed libraries: liblzma.so.5.8.3, lzma.a,
Installed directories: /usr/share/doc/xz-5.8.3, /usr/include/lzma
