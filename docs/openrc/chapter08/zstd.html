5.10. Zstd-1.5.7

Zstandard is a real-time compression algorithm, providing high compression ratios.

Package Information

  • Download HTTP: https://github.com/facebook/zstd/releases/download/v1.5.7/zstd-1.5.7.tar.gz

  • Download SHA256 Sum: eb33e51f49a15e023950cd7825ca74a4a2b43db8354825ac24fc1b7ee09e6fa3

  • Download Size: 2,378 KB

  • Estimated Disk Space: 19.1M

  • Estimated Build Time: less than 0.5 SBU

5.10.1. Installation of Zstd

Prepare Zstd for compilation:

To Compile the Package, issue: 

make prefix=/usr

Now Install the Package, as the root user: 

make prefix=/usr install

5.10.2. Contents of Zstd

Installed programs: zstd, zstdcat (link to zstd), zstdgrep, zstdless, zstdmt (link to zstd), and unzstd (link to zstd)
Installed libraries: libzstd.so.1.5.7, libzstd.a
Installed directories: None
