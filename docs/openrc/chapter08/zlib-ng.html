5.6. Zlib-ng-2.3.3

The Zlib package contains compression and decompression routines used by some programs.

Package Information

  • Download HTTP: https://github.com/zlib-ng/zlib-ng/archive/refs/tags/2.3.3.tar.gz

  • Download SHA256 Sum: f9c65aa9c852eb8255b636fd9f07ce1c406f061ec19a2e7d508b318ca0c907d1

  • Download Size: 2,390 KB

  • Estimated Disk Space: 9M

  • Estimated Build Time: less than 0.5 SBU

5.6.1. Installation of Zlib-ng

Prepare Zlib-ng for compilation: 

./configure --prefix=/usr --zlib-compat

To Compile the Package, issue: 

make

Now Install the Package, as the root user: 

make install

5.6.2. Contents of Zlib-ng

Installed programs:
Installed libraries: libz.so.1.3.1.zlib-ng, libz.a
Installed headers: zlib, zconf, zlib_name_mangling
