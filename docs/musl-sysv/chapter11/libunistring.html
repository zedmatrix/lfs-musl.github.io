11.1. Libunistring-1.4.2

11.1.1. Introduction to libunistring

libunistring is a library that provides functions for manipulating Unicode strings and for manipulating C strings according to the Unicode standard.

Approximate build time: less than 1.0 SBU
Required disk space: 48.9M

11.1.2. Installation of libunistring

First, make a fix required by glibc-2.43 and later:

Prepare libunistring by running: 

./configure --prefix=/usr    \
            --disable-static \
            --docdir=/usr/share/doc/libunistring-1.4.2

Now Build libunistring, issue: 

make

To test the results, issue: 

make check

Now, Install, issue: 

make install

11.1.3. Contents

Installed Programs: None
Installed Libraries: libunistring.so
Installed Directory: /usr/include/unistring and /usr/share/doc/libunistring-1.4.2

Short Descriptions

libunistring.so

provides the unicode string library API
