9.3. zlfs-scripts-20260710T0847Z

Various Bash Start Up scripts moved from the BLFS Book to aid in a better post LFS experience.

Approximate build time: less than 0.1 SBU
Required disk space: 13.5 KB

9.3.1. Installation of zlfs-scripts

Install the package: 

make RELEASE=Zirconium VER=3.0-musl REV=sysv all

The meaning of the make options:

RELEASE=

Gets added to specific os and release files normally installed in chapter 11.

VER=

Populates the specific os release files usually installed in chapter 11.

REV=

This parameter installs specific revision files.

9.3.2. Contents

Installed Program: CurlPaste, /lib/services/dhcpcd, /etc/init.d/sshd
Installed Files: /etc/{inittab, bashrc, profile}
Installed Directories: /etc/profile.d, /etc/bash_completion.d, /etc/skel and /root
