9.11. dejavu-fonts-ttf-2.37

The DejaVu fonts are a font family based on the Bitstream Vera Fonts. Its purpose is to provide a wider range of characters while maintaining the original look and feel.

Approximate build time: less than 0.5 SBU
Required disk space: 11.4M

9.11.1. Installation of Dejavu Fonts TTF

Install the package: 

install -v -d -m755 /usr/share/fonts/dejavu
install -v -m644 ttf/*.ttf /usr/share/fonts/dejavu

9.11.2. Contents

Installed Files: Various ttf files
Installed Directories: /usr/share/fonts/dejavu
